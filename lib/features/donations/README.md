# Donations

عروض التبرع وطلبات المساعدة والتكامل مع المنظمات.

يمر عرض التبرع الآن بدورة تحقق واضحة:

1. يختار المستخدم الدواء وصيدلية التحقق والمنظمة الاختيارية.
2. تراجع الصيدلية سلامة العبوات وتقبل العرض أو ترفضه.
3. تؤكد الصيدلية استلام العبوات المقبولة.
4. تتابع المنظمة العرض بعد اجتياز تحقق الصيدلية.
