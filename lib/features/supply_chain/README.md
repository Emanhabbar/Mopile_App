# Supply Chain

ربط دورة التوريد بين الصيدلية والمستودع ومندوب المستودع.

## الأدوار والوظائف

- `Warehouse`: لوحة المؤشرات، التشغيلات، معالجة الطلبات، إسناد الشحنات، إدارة المندوبين، الفواتير والمدفوعات، المرتجعات، وتنبيهات السحب.
- `Pharmacy`: استعراض المستودعات والكتالوج، إنشاء طلبات التوريد، متابعة الطلبات والشحنات، تأكيد الاستلام، إنشاء المرتجعات، واقتراحات إعادة التخزين.
- `Representative`: متابعة الشحنات المسندة وتحديث مراحل التحميل والتوصيل والوصول والتسليم.

## البنية

- `data/models`: نماذج الاستجابات المطابقة لـ DTOs في ASP.NET.
- `data/data_sources`: جميع استدعاءات `/api/supply-chain`.
- `data/repositories`: مزود مصدر البيانات المعتمد على Dio.
- `presentation/controllers`: Riverpod providers للبيانات المتغيرة حسب الدور.
- `presentation/pages`: مساحة العمل الموحدة التي تعرض واجهة الدور المسجل.

يجب تحديث نماذج هذا الـ feature عند تغيير `SupplyChainDtos.cs` في الباك إند.
