# Intelligence

واجهة خدمات التحليل الاختيارية المتصلة بـ `/api/intelligence`:

- اقتراح البدائل الدوائية للمستخدمين المسجلين.
- توقع نفاد المخزون للصيدلية والمستودع والإدارة.
- فحص صحة خدمة النموذج متاح للإدارة على مستوى مصدر البيانات.

يعرض التطبيق رسالة واضحة عند رجوع `503` لأن خدمة النموذج مستقلة وقد تكون متوقفة، ولا يتعطل باقي التطبيق بسبب ذلك.
